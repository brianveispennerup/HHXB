Brikker
Når \(f(x_1) = ax_1 + b\) og \(f(x_2) = ax_2 + b\), er
\(a = \dfrac{x_2 - x_1}{f(x_2) - f(x_1)}\)
\(f(x_2) - f(x_1) = ax_2 + b - (ax_1 + b) = ax_2 - ax_1 = a(x_2 - x_1)\)
Når \(f(x_1) = ax_2 + b\) og \(f(x_2) = ax_1 + b\), er
dermed har vi \(a = \dfrac{f(x_2) - f(x_1)}{x_2 - x_1}\) hvilket er udtrykket til beregning af hældningskoefficienten.
\(f(x_2) - f(x_1) = ax_1 + b - (ax_2 + b) = ax_1 - ax_2 = a(x_1 - x_2)\)
Vi har dermed, at \(f(x_2) - f(x_1) = a(x_2 - x_1)\)
